O que é JWT?

Um JSON Web Token é como um crachá assinado. Qualquer um pode ler o que está escrito; só quem tem a chave certa consegue provar que o crachá não foi adulterado.

header.payload.signature
  • Header

    Metadados: algoritmo (HS256 ou RS256) e tipo (JWT).

  • Payload

    As claims — dados como sub, exp, nbf, iat, iss, aud e jti. São legíveis, não criptografadas.

  • Signature

    Prova de integridade. Com HS256, HMAC do header + payload com o secret. Com RS256, assinatura RSA-SHA256 com a chave privada. Se alguém mudar uma vírgula, a assinatura quebra.

1
Assinar

O servidor cria o token com as claims — secret (HS256) ou chave privada RSA (RS256).

2
Verificar

Confere assinatura, header (alg/typ), exp e nbf — com o secret ou a chave pública correspondente.

JWT assina, não esconde. Não coloque senhas ou dados sensíveis no payload — qualquer um com o token consegue decodificá-lo.

Uso com go-jwt

HS256 — secret compartilhado, claims tipadas.

package main

import (
	"fmt"
	"time"

	"github.com/bapadua-labs/go-jwt"
)

type MyClaims struct {
	jwt.RegisteredClaims
	Role string `json:"role"`
}

func main() {
	secret := "sua-chave-secreta-com-pelo-menos-32-bytes"

	token, err := jwt.SignHS256(MyClaims{
		RegisteredClaims: jwt.RegisteredClaims{
			Subject:   "usuario-123",
			ExpiresAt: time.Now().Add(24 * time.Hour).Unix(),
		},
		Role: "admin",
	}, secret)
	// ...

	parsed, err := jwt.VerifyHS256As[MyClaims](token, secret, jwt.VerifyOptions{})
	fmt.Println("subject:", parsed.Subject, "role:", parsed.Role)
}

Ainda é possível usar o mapa jwt.Claims com VerifyHS256 se preferir.

RS256 — chave privada para assinar, pública para verificar.

package main

import (
	"crypto/rand"
	"crypto/rsa"
	"fmt"
	"time"

	"github.com/bapadua-labs/go-jwt"
)

type MyClaims struct {
	jwt.RegisteredClaims
	Role string `json:"role"`
}

func main() {
	privateKey, err := rsa.GenerateKey(rand.Reader, 2048)
	// ...

	token, err := jwt.SignRS256(MyClaims{
		RegisteredClaims: jwt.RegisteredClaims{
			Subject:   "usuario-123",
			ExpiresAt: time.Now().Add(15 * time.Minute).Unix(),
		},
		Role: "admin",
	}, privateKey)
	// ...

	parsed, err := jwt.VerifyRS256As[MyClaims](token, &privateKey.PublicKey, jwt.VerifyOptions{})
	fmt.Println("subject:", parsed.Subject, "role:", parsed.Role)
}

Com options — iss, aud, MaxAge, clock skew, MaxTokenLen e revogação.

parsed, err := jwt.VerifyHS256WithOptions(token, secret, jwt.VerifyOptions{
	Issuer:          "meu-issuer",
	Audience:        "minha-api",
	MaxAge:          time.Hour,        // exige iat; rejeita se idade > MaxAge
	EnableClockSkew: true,             // liga a tolerância de relógio
	ClockSkew:       30 * time.Second, // folga em exp/nbf/iat
	MaxTokenLen:     8192,             // rejeita token maior que N bytes
	RevocationStore: jwt.RevocationFunc(func(jti string) bool {
		// consulte Redis/DB do seu app; true = revogado
		return false
	}),
})
// VerifyRS256WithOptions segue o mesmo padrão

Revogação — implemente IsRevoked no app (ex.: Redis). A lib não conecta a banco.

package main

import (
	"context"
	"time"

	"github.com/bapadua-labs/go-jwt"
	"github.com/redis/go-redis/v9"
)

func main() {
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	ctx := context.Background()

	// No logout: rdb.Set(ctx, "jwt:revoked:"+jti, "1", time.Until(expTime))

	store := jwt.RevocationFunc(func(jti string) bool {
		n, err := rdb.Exists(ctx, "jwt:revoked:"+jti).Result()
		if err != nil {
			return true // fail-closed
		}
		return n > 0
	})

	type MyClaims struct {
		jwt.RegisteredClaims
	}

	token, err := jwt.SignHS256(MyClaims{
		RegisteredClaims: jwt.RegisteredClaims{
			Subject:   "usuario-123",
			ID:        "uuid-unico-do-token",
			ExpiresAt: time.Now().Add(15 * time.Minute).Unix(),
		},
	}, "sua-chave-secreta-com-pelo-menos-32-bytes")
	// ...

	parsed, err := jwt.VerifyHS256As[MyClaims](token, "sua-chave-secreta-com-pelo-menos-32-bytes", jwt.VerifyOptions{
		RevocationStore: store,
	})
	// err == jwt.ErrTokenRevoked se o jti estiver na denylist
	_ = parsed
}

Emita tokens com jti único. Sem jti, a checagem de revogação é ignorada. No logout, grave o jti no Redis com TTL alinhado ao exp.

API

SignHS256(claims, secret)
Cria um token JWT assinado com HMAC-SHA256 (exige secret ≥ MinSecretLen); claims pode ser mapa ou struct.
VerifyHS256(token, secret)
Valida secret, assinatura, header, exp e nbf (se presente).
VerifyHS256WithOptions(token, secret, opts)
Como VerifyHS256, e ainda iss/aud/MaxAge/MaxTokenLen/EnableClockSkew+ClockSkew/RevocationStore quando preenchidos em opts.
VerifyHS256As[T](token, secret, opts)
Como VerifyHS256WithOptions, deserializando o payload para T (ex.: struct com RegisteredClaims).
SignRS256(claims, privateKey)
Cria um token JWT assinado com RSA-SHA256 (PKCS#1 v1.5); claims pode ser mapa ou struct.
VerifyRS256(token, publicKey)
Valida assinatura RSA, header, exp e nbf (se presente).
VerifyRS256WithOptions(token, publicKey, opts)
Como VerifyRS256, e ainda iss/aud/MaxAge/MaxTokenLen/EnableClockSkew+ClockSkew/RevocationStore quando preenchidos em opts.
VerifyRS256As[T](token, publicKey, opts)
Como VerifyRS256WithOptions, deserializando o payload para T.
VerifyOptions
Issuer, Audience, MaxAge, MaxTokenLen, EnableClockSkew, ClockSkew e RevocationStore opcionais.
RevocationStore
Interface com IsRevoked(jti string) bool — implemente com Redis/DB do app (a lib não persiste nada).
RevocationFunc
Adapter de função para RevocationStore (ex.: closure com o client Redis).
MinSecretLen
Tamanho mínimo do secret HMAC em bytes (32).
Algorithm / AlgorithmHS256 / AlgorithmRS256
Tipo do algoritmo de assinatura; HS256 e RS256 são válidos.
Algorithm.Valid() / Algorithm.String()
Informa se o algoritmo é suportado e devolve o valor JOSE (ex.: "HS256", "RS256").
Claims
map[string]interface{} — o payload do token.
RegisteredClaims
Struct embutível com iss/sub/aud/exp/nbf/iat/jti para claims tipadas.
Audience
Tipo de aud (string ou array JSON) usado em RegisteredClaims.
ID()
Extrai a claim jti (JWT ID); retorna (string, bool).
IssuedAt()
Extrai a claim iat (Issued At); retorna (int64, bool).
HasIssuer(expected) / HasAudience(expected)
Valida iss (string) e aud (string ou array).
HasValidExp()
true se exp é válido e ainda não expirou (na borda now == exp, já é inválido).
IsValidNbf()
true se nbf está ausente ou now >= nbf.
Validate(opts)
Valida exp/nbf (com ClockSkew se EnableClockSkew) e, se preenchidos, iss/aud/MaxAge (via iat) e RevocationStore (via jti).

Erros

ErrWeakSecret
Secret com menos de 32 bytes em SignHS256 ou VerifyHS256.
ErrInvalidToken
Token malformado, vazio ou payload ilegível.
ErrTokenTooLarge
Token com mais bytes que opts.MaxTokenLen (quando MaxTokenLen > 0).
ErrInvalidSignature
Assinatura não confere (HMAC ou RSA) ou secret incorreto (com tamanho válido).
ErrInvalidTokenType
alg diferente do esperado (HS256/RS256), ou typ presente e diferente de JWT.
ErrInvalidHeader / ErrInvalidPayload
Falha ao serializar header ou payload em SignHS256 ou SignRS256.
ErrExpiredToken
exp ausente, inválido ou expirado.
ErrInvalidNotBefore
nbf no futuro.
ErrInvalidIssuer / ErrInvalidAudience
Issuer ou audience inválidos (quando exigidos em VerifyOptions).
ErrInvalidIssuedAt
iat ausente, inválido ou no futuro além do ClockSkew (quando opts.MaxAge > 0).
ErrInvalidMaxAge
Idade do token desde iat maior que opts.MaxAge (+ ClockSkew se EnableClockSkew).
ErrTokenRevoked
jti presente e RevocationStore.IsRevoked retornou true.

Segurança

O que a lib faz

  • HMAC-SHA256 com comparação timing-safe
  • RSA-SHA256 (RS256) com chave privada/pública
  • Base64 URL-safe (padrão JWT)
  • Valida header (alg esperado; typ = JWT quando informado)
  • Valida exp e nbf automaticamente em Verify*
  • Valida iss/aud/MaxAge (via iat), MaxTokenLen, EnableClockSkew/ClockSkew e RevocationStore (via jti) via Verify*WithOptions
  • Rejeita secrets HMAC com menos de 32 bytes (MinSecretLen / ErrWeakSecret)
  • Rejeita confusão de algoritmo entre HS256 e RS256
  • Claims tipadas com RegisteredClaims e Verify*As[T]
  • Revogação via interface RevocationStore (sem acoplar Redis/DB na lib)
  • Em HS256, use secrets fortes e aleatórios (mínimo obrigatório: 32 bytes).
  • Em RS256, proteja a chave privada; distribua só a chave pública para verificação.
  • Sempre defina exp com tempo de vida curto.
  • Use Verify*WithOptions quando precisar de iss/aud, MaxAge, MaxTokenLen, clock skew ou RevocationStore (com jti).
  • Para revogar tokens, emita com jti único e implemente RevocationStore no seu app (ex.: Redis).
  • Transmita tokens apenas via HTTPS.
